\# QUANTIS Framework™



\## Overview



Il Framework contiene tutte le astrazioni comuni della piattaforma.



Ogni modulo della piattaforma eredita queste classi base.



\## Componenti



\- BaseModule

\- BaseService

\- BaseRepository

\- BaseController

\- BasePlugin

\- BaseDashboard

\- BaseReport

\- BaseWorkflow



\## Regole



Nessuna logica applicativa.



Solo contratti.



Le implementazioni concrete appartengono ai moduli.
