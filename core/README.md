\# QUANTIS Core™



\## Overview



QUANTIS Core™ rappresenta il cuore della Quantis Core Platform™.



Il Core fornisce tutti i servizi comuni utilizzabili da qualsiasi prodotto verticale.



\## Principi



\- Framework First

\- API First

\- Event Driven

\- Domain Driven Design

\- Clean Architecture

\- Plugin Oriented

\- Multi Tenant

\- Cloud Native



\## Moduli



\- Identity

\- Tenant

\- RBAC

\- Audit

\- Event Bus

\- Configuration

\- Licensing

\- Workflow

\- Notification

\- Observability



\## Obiettivo



Consentire lo sviluppo di prodotti verticali senza duplicare codice infrastrutturale.
