# M4 — Enterprise Services Foundation

M4 defines the enterprise services layer of Quantis Core Platform™.

## Services

- Licensing
- Subscription
- Billing
- Provisioning
- Compliance

## Purpose

Enterprise Services provide reusable commercial, operational and compliance capabilities for all future vertical SaaS products.

## Rule

Enterprise Services must remain product-neutral. Vertical products compose services, but must not duplicate service infrastructure.
