# Compliance Service Guide

## Purpose

The Compliance Service manages reusable compliance policies, controls and evaluations.

## Public API

- `CompliancePolicy`
- `ComplianceControl`
- `ComplianceControlStatus`
- `ComplianceEvaluation`
- `ComplianceEvaluationResult`
- `ComplianceService`

## Policy model

Regulations such as GDPR, NIS2, ISO 27001, CAD and AGID guidelines should be represented as policy catalogs.
