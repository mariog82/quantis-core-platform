# Quantis Framework Documentation

## Purpose

This documentation consolidates the M2 Framework layer of Quantis Core Platform™.

## Framework Components

- Contracts
- Runtime Kernel
- Dependency Injection
- Persistence
- API Contracts
- Plugin Runtime
- Workflow Runtime
- Dashboard Runtime
- Reporting Runtime
- Integration Tests

## Architectural Rule

The Framework defines the programming model. It must not contain vertical-specific business logic.
