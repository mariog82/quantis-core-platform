# Core Neutrality Standard

The Core must not contain vertical-specific entities or language.

## Forbidden in Core

- school-specific logic
- healthcare-specific logic
- political campaign-specific logic
- festival-specific logic
- voting/meeting/minutes domain logic unless generalized as workflow/event concepts

## Allowed in Core

- identity
- tenant
- rbac
- audit
- events
- configuration
- observability
- generic workflow abstractions
