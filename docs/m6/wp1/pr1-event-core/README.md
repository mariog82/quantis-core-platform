# M6 WP1 PR1 — Event Core

## Version

`0.6.0-alpha.1`

## Scope

This PR introduces the minimal Event Core for Quantis Core Platform:

- `EventId`
- `EventType`
- `EventMetadata`
- `Event`
- `EventEnvelope`
- `EventSerializer`
- `EventDeserializer`
- `JsonEventSerializer`

## Out of scope

- Publisher
- Subscriber
- Dispatcher
- Dead Letter Queue
- Retry
- Event Bus adapter
