# M6 WP4 Freeze

## Release

`0.6.0-rc.1`

## Milestone

M6 WP4 — Workflow Engine 2.0

## Freeze declaration

The Workflow Engine 2.0 feature set is complete.

From this point onward, allowed changes are limited to:

- defect correction;
- compatibility restoration;
- public API stabilization;
- documentation correction;
- CI and release-gate correction;
- security hardening;
- performance improvements that do not alter frozen contracts.

New workflow features must be scheduled for a later milestone.
