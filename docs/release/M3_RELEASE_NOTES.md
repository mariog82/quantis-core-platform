# Quantis Core Platform™ — M3 Release Notes

## Release

`0.3.0-beta.1`

## Summary

M3 introduces the reusable module layer on top of the M2 Framework baseline.

## Highlights

- Analytics Module for indicators and KPI calculations.
- Reporting Module for reusable report templates.
- Dashboard Module for reusable dashboard widgets.
- Notification Module for provider-neutral notifications.
- Integration tests across reusable modules.
- Consolidated module documentation.
