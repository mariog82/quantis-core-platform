# Quantis Core Platform™ — M2 Release Notes

## Release

`0.2.0-beta.1`

## Summary

M2 transforms Quantis Core Platform™ from a core capability layer into a reusable enterprise application framework.

## Highlights

- Runtime Kernel for module lifecycle management.
- Dependency Injection Container for provider-neutral dependency resolution.
- Persistence contracts with Unit of Work.
- API contracts independent from web frameworks.
- Plugin Runtime with extension points.
- Workflow Runtime for reusable orchestration.
- Dashboard Runtime for provider-neutral dashboard composition.
- Reporting Runtime with renderer model.
- Integration tests across framework components.
- Consolidated framework documentation.

## Compatibility

This is a beta release. Public APIs introduced in M2 are intended to remain stable until `0.3.x`, but may still change before `1.0.0 LTS`.
