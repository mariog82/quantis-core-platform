# M5 Release Notes

## Version

`0.5.0-beta.1`

## Highlights

- Provider-neutral adapter architecture.
- HTTP, database, authentication, storage, messaging, AI, notification, payment and identity provider adapters.
- SDK foundation with Python client primitives and OpenAPI helper.
- Public API stabilization gates.
- Regression checks for all adapter public packages.

## Impact

M5 turns Quantis Core Platform into an integration-ready framework capable of supporting vertical SaaS products without coupling them to specific external providers.
