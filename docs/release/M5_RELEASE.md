# M5 Release

## Status

Released and retained as a historical milestone.

## Version line

M5 corresponds to the `0.5.x` release family of Quantis Core Platform™.

## Scope

M5 consolidated the platform foundations and stabilization tooling, including:

- repository integrity checks;
- test integrity checks;
- public API integrity checks;
- CI stabilization checks;
- release management checks;
- repository audit tooling;
- repository recovery tooling;
- beta and release-candidate stabilization gates.

## Historical compatibility

This document is preserved because the release manager validates the presence of historical release documentation.

The current active release is M6 `0.6.0`. This file must not be used to determine the current repository version.

## Release policy

Historical M5 tests and documentation must validate frozen M5 artifacts without asserting that the active `VERSION` file still contains an M5 version.
