# M6 WP4 Public API Freeze

The following areas are frozen:

- `core.workflow2` public exports;
- workflow definition contracts;
- workflow instance contracts;
- runtime and executor contracts;
- state machine contracts;
- human task contracts;
- timer and scheduler contracts;
- BPMN parser/exporter contracts;
- saga contracts;
- monitoring contracts;
- workflow API models and service;
- `sdk.workflow` public exports.

Breaking changes require a dedicated compatibility decision.
