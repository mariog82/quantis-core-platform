# Quantis Core Platform™ — M4 Release Notes

## Release

`0.4.0-beta.1`

## Summary

M4 introduces the enterprise SaaS operating layer of Quantis Core Platform™.

## Highlights

- Licensing Service for tenant licenses, entitlements and feature gates.
- Subscription Service for plans and tenant subscriptions.
- Billing Service for invoices, totals, tax calculation and payment state.
- Provisioning Service for tenant product activation and deprovisioning.
- Compliance Service for policies, controls and evaluations.
- Enterprise service integration tests.
- Consolidated enterprise services documentation.

## Compatibility

This is a beta release. Public APIs introduced in M4 are intended to remain stable during the M4 beta cycle, but may still change before `1.0.0 LTS`.
