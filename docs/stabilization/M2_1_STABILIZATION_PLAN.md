# Sprint M2.1 — Stabilization

## Purpose

Stabilize the M2 beta baseline before tagging `v0.2.0-beta.1`.

## Scope

- verify all public framework packages;
- verify public exports;
- verify required release documents;
- prevent missing package regressions;
- keep M2 beta freeze coherent before starting M3.

## Tag rule

Do not tag `v0.2.0-beta.1` until all checks are green on `develop`.
