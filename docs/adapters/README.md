# M5 — Adapter & Integration Layer

M5 introduces the Adapter Layer of Quantis Core Platform™.

## Purpose

Adapters provide provider-neutral contracts for integrating external technologies without coupling Core, Framework, Modules or Enterprise Services to a specific vendor.

## Initial package

```text
framework/adapters
```

## Initial contracts

- Adapter
- AdapterContext
- AdapterMetadata
- AdapterResult
- AdapterRegistry
- AdapterFactory
- AdapterRuntime
