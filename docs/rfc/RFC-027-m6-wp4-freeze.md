# RFC-027 — M6 WP4 Freeze

## Compatibility guarantees

- Existing workflow definitions remain loadable.
- Existing workflow instances remain representable.
- Existing public exports remain available.
- SDK method names remain stable.
- OpenAPI operation identifiers remain stable.
- BPMN subset support remains backward-compatible.

## Stabilization scope

- bug fixes;
- release gates;
- documentation;
- security;
- performance;
- compatibility.
