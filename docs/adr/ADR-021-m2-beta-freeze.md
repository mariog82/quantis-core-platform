# ADR-021 — M2 Beta Freeze

## Status

Accepted

## Context

M2 introduced the first complete framework layer of Quantis Core Platform™.

## Decision

Freeze M2 as `0.2.0-beta.1` and establish the current framework public API as a beta baseline.

## Consequences

Future work should move to the next milestone unless it fixes bugs, documentation, compatibility or CI issues in M2.
