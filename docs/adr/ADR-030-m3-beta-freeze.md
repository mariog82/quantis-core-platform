# ADR-030 — M3 Beta Freeze

## Status

Accepted

## Context

M3 introduced the reusable module layer of Quantis Core Platform™.

## Decision

Freeze M3 as `0.3.0-beta.1` and establish the module public API as a beta baseline.

## Consequences

Future work should move to M4 unless it fixes bugs, docs, compatibility or CI issues in M3.
