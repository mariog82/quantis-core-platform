# ADR-039 — M4 Beta Freeze

## Status

Accepted

## Context

M4 introduced the enterprise services layer of Quantis Core Platform™.

## Decision

Freeze M4 as `0.4.0-beta.1` and establish the enterprise services public API as a beta baseline.

## Consequences

Future work should move to the next milestone unless it fixes bugs, documentation, compatibility or CI issues in M4.
