# ADR-023 — Reusable Modules Foundation

## Status

Accepted

## Context

After M2 Framework beta, Quantis needs reusable modules that can be composed into vertical products.

## Decision

Introduce a `modules` layer and the first reusable module skeletons: Analytics, Reporting, Dashboard and Notification.

## Consequences

M3 becomes the foundation for reusable product capabilities shared by all future verticals.
