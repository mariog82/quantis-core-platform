# ADR-085 — M6 Final Release

## Status

Accepted

## Decision

Promote Quantis Core Platform M6 from `0.6.0-rc.1` to stable version `0.6.0`.

## Rationale

The Event Platform, Enterprise Event Platform, CQRS stack and Workflow Engine 2.0
are complete and protected by release gates.

## Consequences

- M6 public APIs become the compatibility baseline for `0.6.x`.
- New features move to M7.
- Changes to M6 are limited to patches, security fixes and compatibility work.
